1. ¿Qué es y para qué sirve?

AWS SNS permite publicar mensajes en topics para distribuir notificaciones a múltiples suscriptores y enviar SMS.

OperaciónQué hace
messaging.publish_to_topicPublica un mensaje en un topic SNS.
messaging.list_topicsLista topics SNS.
messaging.send_smsEnvía SMS, bloqueado por defecto.

2. Prerrequisitos

  • Cuenta AWS con SNS habilitado.
  • Región AWS definida.
  • Usuario/rol IAM con permisos mínimos.
  • Topic SNS creado si se publicará en topics.

3. Configuración en AWS

  1. Crea o identifica el topic SNS.
  2. Crea credenciales IAM de mínimo privilegio.
  3. Si usarás SMS, revisa costos, países permitidos y registros requeridos.

4. Permisos requeridos

sns:ListTopicsListar topics y probar conexión.
sns:PublishPublicar en topics y enviar SMS.

5. Configuración en Ruvic

Completa Access Key, Secret, región, topic por defecto opcional y habilita SMS solo si está autorizado.

6. Verificación

Ejecuta Probar conexión y luego lista topics. Publica o envía SMS solo con autorización explícita.

7. Solución de problemas

AccessDeniedFaltan permisos IAM o región incorrecta.
InvalidParameterTopic ARN, teléfono o atributos inválidos.
SMS bloqueadoActiva ALLOW_SMS solo para uso autorizado.

8. FAQ y seguridad

Usa IAM de mínimo privilegio, no subas claves, confirma publicaciones reales y considera costos/regulación de SMS.
